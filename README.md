## Purpose
The groundwork to becoming a Data Scientist involves combining many differents fields like Computer Science and Mathematics.
Learning how to identify trends in data, build predictive models, and use data pipelines will be tasks assigned to Data Scientists.
This work presents the best practices on how to become a Data Scientist in sophomore year of college.
